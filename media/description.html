Bags full in the middle of a quest? Press one key and the cheapest junk stack in your bags is gone. Press again for the next one.

Junk Drop is a plugin for Daylight UI on WoW: Forever. It fits right into Daylight UI: its key sits under Daylight UI in your key bindings, and its settings have their own page in Daylight UI's options.

Setup

  1. Install Junk Drop next to Daylight UI.
  2. Open Esc > Options > Keybindings > Daylight UI and set a key for Drop cheapest junk.

Prefer typing? /dui dropjunk or /dropjunk does the same.

What it deletes

Each press deletes one stack: the one worth the least (its sell price times how many are in it).

  • Gray items count as junk.
  • Items you marked as junk in Daylight UI's bags count too. You can switch this off.
  • Only stacks worth 10 silver or less go. Pricier junk is left for a vendor. Change the cap in /dui > Plugins > Junk Drop, or set it to 0 for no cap.

What it never deletes

  • Items you locked in Daylight UI's bags.
  • Items in an equipment set, while Daylight UI's "lock sets" option is on.
  • Anything during a fight, or while your cursor is holding an item.

Every delete is named in chat with what it was worth. Want to be extra careful? Turn on Ask before deleting for a yes/no box first.

Requires

  • Daylight UI
  • Daylight UI's Bags module (it comes with Daylight UI) is optional but recommended. With it switched on, Junk Drop also sees the items you marked as junk and skips the ones you locked. Without it, only gray items count.
